# DocXAssist — установщики

Ссылки ниже всегда ведут на **последнюю версию**:

- **Windows 10/11:** [DocXAssist-Setup.exe](https://github.com/documenthelper/DocXAssist-releases/releases/latest/download/DocXAssist-Setup.exe)
- **macOS 13+ (Apple M1–M4):** [DocXAssist.dmg](https://github.com/documenthelper/DocXAssist-releases/releases/latest/download/DocXAssist.dmg)

Все версии и список изменений: [Releases](https://github.com/documenthelper/DocXAssist-releases/releases).

## Windows
- Права администратора не нужны, Python и другие программы ставить не надо.
- Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае»
  (программа пока без цифровой подписи).

## macOS
- Откройте `DocXAssist.dmg` и перетащите DocXAssist в папку «Программы».
- При первом запуске macOS скажет, что не может проверить разработчика (программа пока без подписи Apple):
  откройте «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
- Разрешите «Запись экрана» и «Микрофон», когда программа попросит.

Обновления программа находит и устанавливает сама. Этот репозиторий содержит только готовые установщики.
