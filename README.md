# DocXAssist — установщики для Windows

Скачайте последнюю версию: **[Releases → последний выпуск](https://github.com/documenthelper/DocXAssist-releases/releases/latest)** → файл `DocXAssist-Setup-<версия>.exe`.

- Права администратора не нужны, Python и другие программы ставить не надо.
- Обновления программа находит и устанавливает сама.
- Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае»
  (программа пока без цифровой подписи).

Этот репозиторий содержит только готовые установщики.
